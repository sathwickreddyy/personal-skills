Order Fulfilment Workflow

A state machine drawn in Step Functions grammar: one vertical spine, explicit start and terminal states, and every fan-out enclosed in a labelled container so parallel work is unmistakable.

State grammar

  • Start — filled dot, one per diagram, always at the top
  • State — rounded rect; subtitle carries the type and its retry, timeout, or concurrency
  • Split / join dot — one point in, one point out; never N loose diagonals
  • Container — dashed, labelled PARALLEL or MAP; the only way branch semantics read unambiguously
  • Stacked cards — inside a Map, marks the state that runs per element
  • Catch edge — leaves the right side, labelled with the error name
  • Succeed — ringed dot · Fail — amber pill. Every path ends in one
