Highlight Reel Pipeline

How my-video turns nine raw clips and one audio track into a beat-cut 60-second reel. A sequential pipeline with one recovering catch and a composite step that runs 1800 times.

Props — resolved before frame 0, read on every frame

type HighlightReelProps = {
  clips:               string[];   // 9 paths
  audioOffsetInFrames: number;     // 0 or 900
  beatFrames:          number[];   // [] on catch
  hasAudio:            boolean;    // gates <Audio>
}

assignClipsToBeats(clips, beatFrames, 1800)
  → Array<{ src, from, duration }>

// beatFrames empty ⇒ even distribution,
// 1800 / 9 = 200 frames per clip
