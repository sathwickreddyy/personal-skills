Highlight Reel Pipeline

How my-video turns nine raw clips and one audio track into a beat-cut 60-second reel — from the CLI invocation through prop resolution, per-frame composition, and encode.

Shape key — be consistent

  • Process — a function or component that runs once per invocation
  • Pool — N instances of the same node, count in the label
  • Storage — bytes that outlive the process
  • Degraded path — the flow still completes, with less
  • Solid — synchronous call · blue = control flow
  • Dashed — async or exceptional · green = data flow

Props — what moves between lanes

// resolved in lane 1, consumed in lane 2
type HighlightReelProps = {
  clips:               string[];   // 9 paths
  audioOffsetInFrames: number;     // 0 or 900
  beatFrames:          number[];   // [] on catch
  hasAudio:            boolean;    // gates <Audio>
}

// lane 2 derives cut points from beatFrames
assignClipsToBeats(clips, beatFrames, 1800)
  → Array<{ src, from, duration }>

// 1800 / 9 = 200 frames per clip
