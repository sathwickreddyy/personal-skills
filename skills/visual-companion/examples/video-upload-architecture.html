Video Upload Architecture

Direct-to-storage upload with async transcode. The bytes never touch the API servers, and exactly one process writes completion state back to the database.

Shape key — be consistent

  • Service — a process that handles a request
  • Pool — N interchangeable instances
  • Database — vertical cylinder
  • Queue / stream — horizontal cylinder
  • Blob storage — circle
  • Solid — synchronous · blue = control flow
  • Dashed — async / event · green = data flow

Schema — what the flow writes

videos
  id            uuid      // = video_id, step 1
  status        enum      // pending_upload
                          //  → processing
                          //  → ready | failed
  raw_key       text      // written step 2
  created_at    timestamptz

renditions
  video_id      uuid  fk  // step 12, batched
  height        int       // 1080 / 720 / 480
  bitrate_kbps  int
  output_key    text
  unique (video_id, height)
